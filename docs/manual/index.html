Diffapp Web Pro 取扱説明書

2枚の画像をブラウザで比較し、違いがある場所を自動で見つけて印（矩形）で示す、高精度の画像差分検査アプリです。画像は外部に送信されず、すべてブラウザ内で処理します。

このアプリでできること

  • 左右2枚の画像を読み込み、その差分（違い）を自動検出します。
  • 違いのある箇所をヒートマップと矩形（検出枠）で分かりやすく表示します。
  • 撮影位置や明るさ・色味が多少ずれていても、自動で位置合わせ・色補正してから比較します。
  • 画像を外部サーバーに送らないため、プライバシーを守れます（完全オフライン動作も可能）。

想定ユーザー・利用シーン

  • 製品・基板・印刷物などの「良品」と「検査対象」を見比べて違いを探したい品質検査の担当者。
  • ビフォー／アフターの画像から変化点を素早く見つけたい方。
  • 機密性の高い画像を外部に出さずに差分チェックしたい方。
  • サーバー費用をかけずにブラウザだけで使いたい方。

動作環境・前提

  • PCまたはスマートフォンのモダンWebブラウザ（最新の Chrome / Edge / Safari など）。
  • 高精度モード（DINOv2 を使う意味的差分）には、ONNXモデルの読み込みが必要です。モデルが無くても残り3チャネルで動作します。
  • マルチスレッドWASMを使う場合、配信側に特定のHTTPヘッダ（COOP/COEP）が必要です（開発サーバーでは設定済み）。

使い方（ステップbyステップ）

  1. アプリを開きます。
  2. 比較したい2枚の画像（左画像・右画像）を、それぞれの枠にドラッグ＆ドロップ（または選択）します。
  3. 必要に応じて検査範囲をクロップ（範囲指定）します。
  4. パラメータ（感度・最小検出サイズ・解析解像度・最大検出数・チャネル重み）を調整します。最初は既定値のままで構いません。
  5. 検査を実行すると、内部で位置合わせ→色補正→4種類の差分計算→合成→検出枠抽出が行われます。
  6. 結果として、違いのある箇所がヒートマップと矩形で表示されます。スコアの高い順に上位N件が示されます。
  7. 検出が多すぎる／少なすぎる場合は「感度」や「最小検出サイズ」を調整して再実行します。

主な機能

  • 4チャネル差分検出（重み付き合成）:
    1. MS-SSIM … 構造的な差分（ノイズに強い）
    2. CIEDE2000 … 知覚的な色差
    3. DINOv2 … 意味的差分（照明・ノイズに頑健）
    4. Canny + 距離変換 … エッジ位置のズレ
  • 自動整列: OpenCV.js による ORB + RANSAC ホモグラフィ整列、CLAHE 照明均一化、ヒストグラムマッチ色正規化。
  • 後処理: Otsu二値化 → モルフォロジー → 連結成分 → NMS で検出枠を抽出。
  • 調整可能なパラメータ: 感度（既定0.5）、最小検出サイズ（既定0.4%）、解析解像度（既定512px）、最大検出数（既定20）、チャネル重み。
  • PWA対応: Service Worker で完全オフライン化、ホーム画面に追加可能。
  • 完全ローカル処理: 画像の外部送信・外部API呼び出しは一切なし。

よくある質問・トラブルシューティング

  • Q: 違いを正しく検出してくれません。
    A: 「感度」を上げると拾いやすく、下げると拾いにくくなります。また「最小検出サイズ」を小さくすると細かい違いも検出します。位置がずれている場合は自動整列されますが、極端なズレでは精度が落ちることがあります。
  • Q: 高精度モード（DINO）が使えません。
    A: ONNXモデル（約90MB）の取得に失敗している可能性があります。モデルが無くても残り3チャネルで動作し、UI上でDINOは自動的に無効化されます。
  • Q: 処理が重いです。
    A: 「解析解像度」を下げると軽くなります。大きいほど細部に強い反面、処理が重くなります。
  • Q: 画像はどこかに送られますか。
    A: 送られません。すべてブラウザ内で処理され、外部通信は行いません。
